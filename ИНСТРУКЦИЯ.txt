VOCAL ATMOSPHERE — проект VST3 для Windows x64

ВНИМАНИЕ: в этом архиве исходный код, а не готовый файл VST3. Плагин надо собрать. Он создаёт атмосферную обработку вокала, а не копирует голос и не гарантирует совпадения с каким-либо конкретным треком. Автотюна и коррекции высоты в нём нет.

СБОРКА БЕЗ УСТАНОВКИ ПРОГРАММ ЧЕРЕЗ GITHUB ACTIONS
1. Создайте аккаунт GitHub, если его нет, и новый репозиторий.
2. Загрузите в корень репозитория содержимое папки VocalAtmosphere, включая скрытую папку .github (через git или веб-интерфейс). CMakeLists.txt должен находиться в корне репозитория.
3. Откройте вкладку Actions, выберите Build Windows VST3 и нажмите Run workflow. При первом запуске может потребоваться разрешить Actions.
4. После завершения откройте запуск и скачайте артефакт Vocal-Atmosphere-Windows-VST3. Если сборка завершится ошибкой, откройте лог и пришлите его для исправления.
5. Из скачанного архива скопируйте целиком папку Vocal Atmosphere.vst3 в C:\Program Files\Common Files\VST3\ (может потребоваться разрешение администратора). В некоторых DAW сканирование плагинов нужно запустить вручную.

ЛОКАЛЬНАЯ СБОРКА
Установите Visual Studio 2022 с компонентом Desktop development with C++, CMake и Git. В PowerShell из папки проекта:
cmake -S . -B build -A x64
cmake --build build --config Release --target VocalAtmosphere_VST3 --parallel
Готовая папка находится в build\VocalAtmosphere_artefacts\Release\VST3\.
При конфигурации нужен интернет для загрузки JUCE.

КАК НАСТРОИТЬ
Поставьте плагин на дорожку вокала. Начните со значений по умолчанию.
Input — входной уровень; Compression — плотность; Warmth — насыщение; Delay mix и Delay time — количество и время эха; Reverb mix — количество реверберации; Output — итоговый уровень. Если вокал тонет в эффектах, убавьте Delay и Reverb. Если есть перегруз, уменьшите Input или Output. Время задержки задаётся вручную в миллисекундах, не синхронизируется с темпом. Во избежание кликов меняйте Delay time между фразами или при остановленном воспроизведении.
Плагин не является лимитером. Используйте аккуратные уровни и проверяйте пики в DAW.

FL STUDIO 26
После установки плагина откройте Options → Manage plugins → Find installed plugins. Найдите Vocal Atmosphere и отметьте звёздочкой. Откройте Mixer (F9), выберите канал с вокалом и загрузите Vocal Atmosphere в свободный слот эффектов. Регулируйте ручки мышью; двойной щелчок возвращает значение по умолчанию. Значения сохраняются в проекте DAW. Проверяйте входной и выходной уровень по индикаторам FL Studio. Это исходный проект; совместимость сборки с FL Studio 26 не была проверена.
